# Power BI na Real — Materiais e Templates

Repositório de materiais práticos sobre Power BI, modelagem de dados, DAX e indicadores gerenciais produzidos para a comunidade Power BI na Real.

## Objetivo

Centralizar exemplos reutilizáveis que conectam conceitos técnicos a situações reais de negócio, com foco em análise de dados, custos, desempenho e tomada de decisão.

## Conteúdo disponível

### Template de KPI de custos

O diretório [`templates/kpi-custos`](templates/kpi-custos) apresenta um modelo voltado ao acompanhamento de indicadores de custos.

O catálogo será ampliado progressivamente com novos exemplos, bases didáticas, medidas e templates.

## Temas do repositório

- Power BI
- DAX
- Power Query
- Modelagem dimensional
- Indicadores gerenciais
- Análise de custos
- Boas práticas de visualização

## Como utilizar

1. Navegue pelos diretórios do repositório.
2. Leia o README específico de cada material.
3. Faça o download ou clone o projeto:

```bash
git clone https://github.com/mildestinos/powerbi-na-real-materials.git
```

4. Adapte os exemplos à sua realidade, validando medidas, relacionamentos e regras de negócio.
